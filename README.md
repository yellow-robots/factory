# factory

Machinery that takes a project from its next declared version to a deployed one. Version 2;
v1 lives in `yellow-robots/factory-v1`.

Start by running, not reading:

```sh
make            # list targets
make setup      # toolchain (uv)
make next       # where we are: version, next declared version, the red tests
make test       # how well it stands
```

Where things live:

- `versions/` the factory's own next goals, one file per version (the next one is the lowest without a tag)
- `docs/decisions/` why things are the way they are, append-only, numbered
- `tests/` tests marked `next` are the position: red on purpose until the next session makes them green
- `CHANGELOG.md` generated by `make changelog` from conventional commits; never edited by hand

The design reference is in the Obsidian vault, `04 projects/factory/factory-v2-design.md`. It is
an asset to draw from, not a specification to implement: see `docs/decisions/0002-thinnest-loop.md`.
