## Findings

### A NaN in a record aborts the table

severity: smell
verified: yes
judged: test test_a_number_that_is_not_finite_is_a_measure_the_run_lacks

`json.loads` accepts the `NaN` literal and `_number_text` did `int(value)` on it, so one record with `NaN` in requests ended `evals.main` with a ValueError after every run of the set was paid for, where the median used to skip it. Reproduced with three records, the first `"requests": NaN`: the table before the change printed 2, after it raised. Rated a smell by the reviewer since the builder writes no NaN; a test and a follow-up build all the same, since one bad record must not end the set.

### min-max reads two ways for a negative or an exponent

severity: smell
verified: yes
judged: none: requests, cost and seconds are never negative, and a cost under 1e-5 dollars has not occurred in 99 records

`_spread_text([-3.0, 5.0])` is `-3-5`, `[-3.5, -1.0]` is `-3.5--1`, `[1e-5, 2e-5]` is `1e-05-2e-05`: the format the Goal states, for values the three measures do not take.

### A cost under a microdollar prints as 0.0

severity: smell
verified: yes
judged: none: inherited from the median, whose text the spread's ends must match, and the two agree

`_number_text(1e-7)` is `0.0`, so two such costs spread `0.0-0.0`; the median prints the same.

### The module docstring names medians alone

severity: smell
verified: yes
judged: test test_the_module_docstring_names_the_spread, seed stale-docstring-case

The docstring of `evals.py` said the medians of the builder's numbers while README, AGENTS.md and the version note said the spread; the printed header matched the prose and the docstring did not. A behaviour the module docstring describes changed and the docstring did not: the shape of the first quality case.

### The spread is emitted only inside the median loop

severity: smell
verified: yes
judged: none: SPREAD_COLUMNS is a subset of MEDIAN_COLUMNS by construction, and a test of it would pin a constant

A name added to `SPREAD_COLUMNS` that is not in `MEDIAN_COLUMNS` would print nothing, without a word. Today the subset holds.
