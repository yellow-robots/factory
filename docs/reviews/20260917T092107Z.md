## Findings

### A pass word that is not UTF-8 or cannot be read aborts the whole set

severity: defect
verified: yes
judged: test test_a_word_that_cannot_be_decoded_is_not_whole_and_the_other_cases_run

`_case` read `pass.txt` with an unguarded `read_text`, so a word in latin-1, UTF-16 or a file that cannot be read raised out of `_whole` and out of `main`: one bad file stopped the whole cases beside it, where the Goal says such a case is not whole, a usage error when named and a skip when not. Reproduced with a repository of two cases, `alpha` green and `beta` a latin-1 word, the builder patched to raise if reached: `UnicodeDecodeError` from `evals.main` named and unnamed alike.

### A cap reached or a check without a sandbox counts as the model's tool error

severity: defect
verified: yes
judged: test test_a_cap_or_a_check_without_a_sandbox_is_a_wall_and_not_the_models_error

`runs.tool_errors` left out only the three refusal prefixes, so `error: cap reached (30 writes and edits); report now`, `error: cap reached (8 checks); report now` and `error: no sandbox; check is not available in this run`, the walls' returns, landed in the column the seed made for the model's lapses. The Goal's own words did it, "not a wall's refusal, the returns `refused` counts", and the Goal is amended. Reproduced on a record of six wall returns: three counted. Latent today, none of the 101 records holds a cap's return.

### `cases` is hidden in every checkout, not only this repository's

severity: smell
verified: yes
judged: test test_the_harness_names_what_else_to_hide_for_a_run, test test_a_name_the_harness_adds_is_hidden_like_the_record

`HIDDEN` is program-wide and the one `Tools(...)` call never overrides it, so any checkout with a top-level `cases/`, an ordinary name, loses it to every tool, and the builder could no longer be given a seed touching a case of this repository. The other five hidden names are what running the program leaves behind; this one was the harness's convention written into the wall. The pass-rate-error Goal is amended: `builder.main` takes the names the harness adds and `evals.py` passes `cases`; the builder's own hidden names are five again.
