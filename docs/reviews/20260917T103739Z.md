## Findings

### A held-out test the check never runs counts as a held-out pass

severity: defect
verified: yes
judged: test test_held_out_holds_test_files_at_its_top_alone_and_only_for_a_green_case

`copytree` kept the tree of `held_out/` and `unittest discover` does not enter a directory without `__init__.py`, and nothing checked `held_out/` at all, so a nested test, or a `held_out/` with no test, left the second check green on the root's tests alone and the column counted a pass. Reproduced with the reviewer's probe: a `held_out/` holding `notes.md` only gave green, held-out and passed 1 1 1. The Goal is amended: `held_out/` holds test files at its top and nothing else, or the case is not whole.

### The held-out copy overwrites the case's own test and the builder's work

severity: defect
verified: yes
judged: test test_a_held_out_file_the_worktree_already_has_is_a_failed_run_with_the_record_kept, test test_held_out_holds_test_files_at_its_top_alone_and_only_for_a_green_case

`dirs_exist_ok=True` replaced whatever the worktree had under the same name, the case's visible test, a file the builder wrote, the repository's own tests, after the record was taken; the held-out check then graded a checkout the builder did not produce. Reproduced: `held_out/test_alpha.py` and `held_out/f.py` replaced both at the second check and the row read green. The Goal is amended: a held-out file named like the case's test is not whole, and one whose path the worktree already has after the build is a failed run with no held-out check.

### A raising held-out check throws away a finished green build's record

severity: defect
verified: yes
judged: test test_a_held_out_check_that_raises_is_one_failed_run_and_the_set_goes_on

The held-out check ran inside `_run_case` before the record was returned, so its exception reached `main`, which set the record to None: a build that ran, cost money and left a green record vanished from the table. Reproduced: exit 1, the row empty, the record on disk green with its cost. The attended agent's own test pinned the loss and is amended: the record stays, green counted and cost summed, no held-out pass.
