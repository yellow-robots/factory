## Idea

Each run's world is a fresh repository of one commit outside this one, made from an export of a pinned commit with no `runs/`, no `cases/` and none of the notes that describe the set, `docs/`, `AGENTS.md`, `CLAUDE.md` and `CHANGELOG.md`, the case's goal, visible test and files added in that commit; nothing of this repository's history is in its `.git`. The pin is named in the harness and moved on purpose, so two set runs on one pin share a world. The held-out tests run on a fresh export with the run's diff applied, never in the world the model had. `README.md` stays for the two cases whose goals name it, its paragraph on the set moved to `cases/README.md`. The price: a run no longer sees what the factory's own builds see, the notes among it. It replaces notes-hidden-from-the-set. The test of this repository's own cases moves to a file the export leaves out, beside the cases it reads. The export takes its commit as an argument, the set's pin its first use: harder-capability-cases and analyst-on-api-models each need a world at another commit. A case is shown whole at the pin with no model, red as exported and green with the diff of a run that passed, before the set is run on it. What the export makes is what build-from-a-pushed-branch builds on, a checkout that is not this repository.
