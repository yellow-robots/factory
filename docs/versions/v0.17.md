# v0.17: what a run costs, and what its work is worth

v0.16 gave a run a bigger budget and a way to land inside it; reading the records afterwards said the budget was derived from a fiction and that the money was somewhere else entirely. Seven of thirteen capped builds left a tree the builder's own check had passed, and every one was thrown away for want of a report -- ninety cents, seventeen per cent of everything this factory has ever spent on builds, finished work binned because nobody wrote five bullet points about it. This version takes that work. It also stops pretending the budget measures reading: decomposed, the walk counts files, and more than half of what it counts is the vault and the evaluation set the builder never opens. What replaces it is the quantity the budget was always a proxy for -- a run's cost, which the records separate cleanly, and which the price table already knows how to compute once the model is named by a label that table recognises.
