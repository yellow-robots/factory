# v0.14: a build asked through git

The factory works as a deployment that is sent a seed of a project: it takes a repository, a branch and a seed's path and answers with a commit pushed to that branch, and it keeps the record of every run in a store of its own, outside every project; its own repository is the first such project and no exception.
