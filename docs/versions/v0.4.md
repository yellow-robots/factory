# v0.4: the gate

In flight. The version that makes the documents honest: a deterministic gate that validates the
vault against the template's stages, renders what is derived, and cuts a version's tag and
changelog; the vault protected from the builder's writes; the world's commit recorded in every
run; the run records committed as the baseline for the evals.

Built by the factory from the attended agent's red tests, except `commit-the-runs`, which is the
attended agent's own git work. The first version specified as seeds.
