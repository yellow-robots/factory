# v0.13: every build on the list

The gate refuses a release whose builds git cannot list: a build commit whose `Built-By` line git's trailer parser does not read, or whose run is not a committed record, so the builds of a version are what `git log` derives and nobody has to look.

One seed so far, found by the attended agent reading the log on 2026-09-17. Built by the factory from the attended agent's tests.
