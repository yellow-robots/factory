# v0.22: fewer requests, and the loop counted

The day v0.21 shipped, two thirds of what its builds spent went to runs that read and never wrote: 20 builds, $1.96 at the flat rate, 9 of them red at the soft cap for $1.31. A read is 300 lines and a request, every request carries the conversation again and thinks before it answers, and reasoning was 80% of a capped run's cost; and twice a run has died on the argument the model keeps inventing for `read`. This version makes a read as large as the model asks for, gives it that argument, and makes a mistake in a call's shape cost a request instead of the run, so a cold run of this repository reads `builder.py` in two requests where it took six. And it makes the loop's own numbers a command, so the next version is opened on what the last one cost -- builds, red, capped, dollars, reviews and what they found -- and not on a tier written the day a seed was filed.
